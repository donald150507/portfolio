# Portfolio — Donald Zinsou

Portfolio personnel créatif, responsive et interactif, réalisé en **HTML, CSS et JavaScript natifs**.

## Aperçu

Ouvrir `index.html` dans un navigateur. Aucune installation, compilation ni dépendance JavaScript nécessaire.

## Fichiers

- `index.html` : contenu et structure du site
- `style.css` : design responsive, typographies et animations
- `script.js` : menu mobile, filtres des projets et animations au défilement

## Publication avec GitHub Pages

1. Aller dans **Settings → Pages** du dépôt.
2. Sous **Build and deployment**, choisir **Deploy from a branch**.
3. Sélectionner la branche **main**, puis le dossier **/(root)**.
4. Enregistrer. L'adresse prévue est : https://donald150507.github.io/portfolio/

## Personnalisation

Modifier les textes et les projets dans `index.html`, les couleurs et styles dans `style.css`, ainsi que les interactions dans `script.js`.
